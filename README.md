# 🏆 FIFA World Cup 2026™ — WorldCup Hub

Site informativo e interativo sobre a Copa do Mundo FIFA 2026, com álbum digital de figurinhas Panini, contagem regressiva, histórico de edições e calendário de grupos.

---

## 📁 Estrutura de arquivos

```
/
├── index.html     → Estrutura HTML da página
├── styles.css     → Todos os estilos visuais (CSS)
├── script.js      → Dados do álbum e lógica interativa (JS)
└── README.md      → Este arquivo
```

---

## 🚀 Como usar

Basta abrir o `index.html` direto no navegador — não requer servidor, build ou dependências externas.

> ⚠️ Os três arquivos (`index.html`, `styles.css`, `script.js`) precisam estar na **mesma pasta**.

---

## 📌 Seções do site

| Seção | Descrição |
|---|---|
| **Hero** | Apresentação da Copa 2026 com estatísticas rápidas |
| **História** | Timeline completa de todas as 22 edições (1930–2022) |
| **Copa 2026** | Favoritos ao título, lesionados e craques eliminados |
| **Countdown** | Contagem regressiva para o primeiro jogo |
| **Álbum Panini** | Gerenciador de figurinhas com filtros e progresso salvo |
| **Jogos** | Grade dos 12 grupos com as 48 seleções |

---

## 🎴 Álbum de Figurinhas

- **~900+ figurinhas** cobrindo todas as 48 seleções + coleções especiais
- Clique numa figurinha para marcar como **coletada**
- Progresso salvo automaticamente via **localStorage** do navegador
- Filtros: Todas · ⭐ Especiais · Faltam · Coletadas
- Barra de progresso global no topo da página

### Coleções incluídas
- We Are 26 / Cup 26 / Bola e Países-Sede
- 12 Grupos × 4 Seleções (20 figurinhas cada)
- Histórico de Copas (figurinhas especiais)
- Extra Stickers
- Coca-Cola Collection

## 🛠️ Tecnologias

- **HTML5** semântico, sem frameworks
- **CSS3** com variáveis customizadas (`--blue`, `--green`, etc.)
- **JavaScript** vanilla (ES6+), sem dependências
- **Google Fonts** — Noto Sans
- **localStorage** para persistência do álbum
